# 🌐 Ankit Portfolio Website

A responsive portfolio website developed for showcasing the professional profile, achievements, and academic work of Ankit Sharma.

## 📖 Overview

This project is a clean and responsive portfolio website designed to present professional information, skills, achievements, and contact details in a modern web interface.

## ✨ Features

* Responsive design for desktop and mobile devices
* Professional portfolio layout
* About section
* Skills section
* Contact information section
* Dark mode support
* Social media integration

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Git
* GitHub Pages

## 🏃 How to Run Locally

```bash
git clone https://github.com/CodeBytesRaj/ankit-portfolio.git

cd ankit-portfolio
```

Open `index.html` in your browser.
